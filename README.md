# Portfolio Gabriele Alleruzzo

Sito portfolio personale, realizzato con React + Vite.

## Sviluppo

```bash
npm install
npm run dev
```

## Build di produzione

```bash
npm run build
npm run preview
```

## Stack

- React 18 + React Router
- Vite
- Multilingua IT/EN/DE gestita tramite `LanguageContext` (`src/i18n`)
- Contenuti progetti in `src/data/projects.js`

Deploy attuale: [Vercel](https://gabriele-alleruzzo-portfolio.vercel.app/).
